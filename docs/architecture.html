ReportAgent 架构与链路

一个问题进来后在哪里解析、哪里改写、何时调用模型和工具、开关如何改变路径，以及报告如何生成。数字只由代码计算，Agent 负责理解问题、选工具和写文字。

图 1　系统分层：职责如何划分

上层只依赖下层。对话和报告共用分析、文字校验和数仓访问。

图 2　提问进入：解析、改写和辅助思考

这里决定问题的最终形态和是否联网。真正的意图识别发生在图 3：意图识别 Agent 把问题转成结构化工具参数。

图 3　意图识别与工具：什么时候调用什么

意图识别 Agent 每轮决定调用工具还是直接回答。联网开关决定它有没有 web_search；关闭时即使尝试调用也会被拒绝。

图 4　形成报告：两个入口，一条流水线

表单入口不经过意图识别 Agent。两个入口都走同一条流水线，结果都存成任务，可归入项目。

主路径分支或回流虚线框：可选，由开关控制

Agent 分工

Agent 按职责命名，模型由环境变量配置。报告撰写 Agent 用 WRITER_AGENT_MODEL，其余用 AGENT_MODEL，被限流时切到 AGENT_FALLBACK_MODEL。

Agent职责什么时候运行带工具失败时
问题改写 Agent把依赖上下文的追问改成独立问题有历史提问时否用原问题
辅助思考 Agent梳理理解和取数思路开关打开时否不展示思路
意图识别 Agent选工具和参数，组织最终回答每轮，最多 4 轮是结束并提示重试
回答修正 Agent重写没过校验的回答校验不过且已有结果否用规则结论
报告撰写 Agent写报告的 4 段文字每份报告，并发 2 路否用规则模板

各种情况怎么走

情况链路用户看到
首轮问数不改写 → 问答库匹配 → 意图识别 Agent 选 query_metrics → SQL → 校验结论、表格、图表、SQL
追问“那里约州呢”问题改写 Agent 改成独立问题并展示，再走同样流程回答基于改写后的问题
辅助思考打开辅助思考 Agent 先写思路，再进入工具循环可折叠的思考过程，等待更久
辅助思考关闭跳过思路，直接进入工具循环响应更快；意图识别 Agent 仍自行选工具
联网打开，问外部信息意图识别 Agent 多一个 web_search 工具，每问最多 3 次结论附来源列表；网页内容只当数据
联网打开，问内部数据意图识别 Agent 仍调用数据工具，不一定搜索数字来自数仓
联网关闭，问外部信息没有搜索工具；Agent 即使调用也会被拒绝说明查不到，或提示可打开开关
联网超出每小时上限提示后按关闭处理这次不联网
搜索失败或无结果错误写回意图识别 Agent，由它说明没查到不编造外部信息
问“为什么涨了”意图识别 Agent 优先调用 explain_change因素贡献表和下钻结论
筛选值不存在工具返回可选值，意图识别 Agent 修正或追问任务卡显示“正在调整”
问题超出范围意图识别 Agent 不调工具直接回答，仍要过校验说明做不到和能做什么
校验不通过回答修正 Agent 重写一次，仍不过改用规则结论显示已换成规则结论
Agent 限流或失败主模型限流切备用；再失败结束提示稍后重试；报告文字退回模板
未配置 Agent 模型对话直接结束报告和漏斗不受影响
用户点停止前端中断连接，已产生内容保存显示任务已终止
周次未结束或无数据报告和漏斗在取数前后检查提示原因和最近完整周
问预测或打开预测报告forecast_sales 取周度历史；同一起点和指标 1 小时内复用训练结果；回测赢过基线才用模型的数字未来 4 周预测、80% 区间、回测对比和 SHAP；模型加载失败时只给基线
问哪里异常或打开体检business_checkup 用回测预测当预期，筛出偏差超过其余周且金额达标的范围按金额排序的清单、单量和单件价值拆解、子类和品牌、下周预计
问“如果客单价提 5%”what_if_forecast 在下周预测上做恒等式试算结果、差额、这个幅度历史出现几次；说明不代表因果
打开漏斗看板不经过 Agent，页面表单和链接直接查数选维度、点名称下钻，10 分钟缓存
